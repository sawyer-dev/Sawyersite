## Overview

This study let me dig into rendering and loading performance optimization, along with performance profiling, using Unity.

## What I tried

- **Static batching, GPU instancing, and occlusion culling** reduce the rendering work done each frame.
- **Asynchronous additive scene loading** moves level loading off the critical path of gameplay.

## Results

- Combining static batching, GPU instancing, and occlusion culling improved the performance of a sample FPS project by 20% overall.
- Asynchronous additive scene loading eliminated the performance spikes that happened when loading into new levels.
