## Overview

Space Escape is a virtual reality puzzle game inspired by physical escape rooms. The player solves a series of puzzles to get a spaceship repaired and working before time runs out and a nearby star goes supernova.

It was created for CS4099, Directed Study in Computer Science, in spring 2022, using Unreal Engine 4.

## My contributions

- Developed modular gameplay systems.
- Built the user interface.
- Implemented scene management for the escape-room flow.
